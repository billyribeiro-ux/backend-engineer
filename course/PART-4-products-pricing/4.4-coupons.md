# Lesson 4.4 — Coupons and Promo Codes

## The Coupon Data Model

From the schema in Lesson 1.2:

```sql
coupons:
  code           -- the string users type in (e.g., 'LAUNCH20')
  discount_type  -- 'percent' or 'fixed'
  discount_value -- 20 (percent) or 500 (cents, for fixed)
  max_uses       -- NULL = unlimited
  current_uses   -- how many times redeemed so far
  expires_at     -- NULL = never expires
  applies_to     -- 'all', 'products', 'plans'
  is_active      -- can be deactivated without deletion

coupon_redemptions:
  coupon_id  -- which coupon
  user_id    -- who used it
  payment_id -- which payment it was applied to
  -- UNIQUE(coupon_id, user_id) -- can only use each coupon once
```

## Coupon Validation Logic

Validation must answer five questions:

1. Does this coupon code exist and is it active?
2. Has it expired?
3. Has it reached its maximum uses?
4. Has this specific user already used it?
5. Does it apply to what the user is trying to buy?

```javascript
// services/coupons.js

export async function validateCoupon(code, userId, resourceType, resourceId) {
  // 1. Find the coupon
  const coupon = await db.query(`
    SELECT * FROM coupons
    WHERE UPPER(code) = UPPER($1)
      AND is_active = true
    LIMIT 1
  `, [code])
  
  if (!coupon.rows.length) {
    return {
      valid: false,
      reason: 'COUPON_NOT_FOUND',
      message: 'This coupon code is not valid.',
    }
  }
  
  const c = coupon.rows[0]
  
  // 2. Check expiry
  if (c.expires_at && new Date(c.expires_at) < new Date()) {
    return {
      valid: false,
      reason: 'COUPON_EXPIRED',
      message: 'This coupon has expired.',
    }
  }
  
  // 3. Check max uses
  if (c.max_uses !== null && c.current_uses >= c.max_uses) {
    return {
      valid: false,
      reason: 'COUPON_MAX_USES_REACHED',
      message: 'This coupon has reached its maximum number of uses.',
    }
  }
  
  // 4. Check if user has already used this coupon
  const alreadyUsed = await db.query(`
    SELECT 1 FROM coupon_redemptions
    WHERE coupon_id = $1 AND user_id = $2
    LIMIT 1
  `, [c.id, userId])
  
  if (alreadyUsed.rows.length) {
    return {
      valid: false,
      reason: 'COUPON_ALREADY_USED',
      message: 'You have already used this coupon.',
    }
  }
  
  // 5. Check applies_to
  if (c.applies_to !== 'all') {
    if (c.applies_to === 'products' && resourceType !== 'product') {
      return {
        valid: false,
        reason: 'COUPON_NOT_APPLICABLE',
        message: 'This coupon only applies to one-time product purchases.',
      }
    }
    if (c.applies_to === 'plans' && resourceType !== 'plan') {
      return {
        valid: false,
        reason: 'COUPON_NOT_APPLICABLE',
        message: 'This coupon only applies to subscriptions.',
      }
    }
  }
  
  // All checks passed — return the valid coupon with discount calculation
  return {
    valid: true,
    coupon_id: c.id,
    stripe_coupon_id: c.stripe_coupon_id,
    discount_type: c.discount_type,
    discount_value: c.discount_value,
  }
}


export function applyDiscount(amountCents, discountType, discountValue) {
  if (discountType === 'percent') {
    // discountValue is 0-100
    const discount = Math.floor(amountCents * (discountValue / 100))
    return Math.max(0, amountCents - discount)
  }
  
  if (discountType === 'fixed') {
    // discountValue is in cents
    return Math.max(0, amountCents - discountValue)
  }
  
  return amountCents
}
```

## The Validation Endpoint

```javascript
// handlers/coupons.js

export async function validateCouponEndpoint(req, res) {
  const { code, product_id, plan_id } = req.body
  
  const resourceType = product_id ? 'product' : plan_id ? 'plan' : null
  const resourceId = product_id ?? plan_id ?? null
  
  const result = await validateCoupon(code, req.user.id, resourceType, resourceId)
  
  if (!result.valid) {
    // We return 200 even for invalid coupons — it's not an error, it's a validation result
    return res.json({
      valid: false,
      reason: result.reason,
      message: result.message,
    })
  }
  
  // Calculate the discounted price to show the user before checkout
  let originalAmountCents = null
  if (product_id) {
    const price = await db.query(`
      SELECT amount_cents FROM prices WHERE product_id = $1 AND is_current = true
    `, [product_id])
    originalAmountCents = price.rows[0]?.amount_cents
  } else if (plan_id) {
    const price = await db.query(`
      SELECT amount_cents FROM prices WHERE plan_id = $1 AND is_current = true
    `, [plan_id])
    originalAmountCents = price.rows[0]?.amount_cents
  }
  
  const finalAmountCents = originalAmountCents
    ? applyDiscount(originalAmountCents, result.discount_type, result.discount_value)
    : null
  
  return res.json({
    valid: true,
    discount_type: result.discount_type,
    discount_value: result.discount_value,
    original_amount_cents: originalAmountCents,
    final_amount_cents: finalAmountCents,
    savings_cents: originalAmountCents ? originalAmountCents - finalAmountCents : null,
  })
}
```

## Creating Coupons (Admin)

When creating a coupon, create it in Stripe first, then store locally with the Stripe coupon ID:

```javascript
export async function createCoupon(req, res) {
  const {
    code,
    discount_type,
    discount_value,
    max_uses,
    expires_at,
    applies_to = 'all'
  } = req.body
  
  // Check for duplicate code
  const existing = await db.query(`
    SELECT id FROM coupons WHERE UPPER(code) = UPPER($1)
  `, [code])
  
  if (existing.rows.length) {
    return res.status(409).json({
      error: { code: 'COUPON_CODE_EXISTS', message: 'A coupon with this code already exists.' }
    })
  }
  
  // Create in Stripe
  const stripeCoupon = await stripe.coupons.create({
    name: code,
    ...(discount_type === 'percent'
      ? { percent_off: discount_value }
      : { amount_off: discount_value, currency: 'usd' }
    ),
    max_redemptions: max_uses ?? undefined,
    redeem_by: expires_at ? Math.floor(new Date(expires_at).getTime() / 1000) : undefined,
  })
  
  const coupon = await db.query(`
    INSERT INTO coupons (
      id, code, discount_type, discount_value, max_uses,
      expires_at, applies_to, stripe_coupon_id
    )
    VALUES (uuid_generate_v4(), $1, $2, $3, $4, $5, $6, $7)
    RETURNING *
  `, [
    code.toUpperCase(),
    discount_type,
    discount_value,
    max_uses ?? null,
    expires_at ?? null,
    applies_to,
    stripeCoupon.id,
  ])
  
  return res.status(201).json({ coupon: coupon.rows[0] })
}
```

## The Race Condition in Coupon Redemption

There's a subtle bug that many implementations miss:

1. User A validates coupon: `current_uses = 99`, `max_uses = 100` → valid
2. User B validates coupon at the same time: `current_uses = 99`, `max_uses = 100` → valid
3. User A redeems: `current_uses = 100`
4. User B redeems: `current_uses = 101` — OVER THE LIMIT

Both passed the validation check, but both incremented the counter, exceeding max_uses.

**Fix: Use a database-level atomic increment with a guard:**

```sql
-- Atomic: increment current_uses only if it's still below max_uses
-- Returns the updated row if successful, 0 rows if at max
UPDATE coupons
SET current_uses = current_uses + 1
WHERE id = $1
  AND (max_uses IS NULL OR current_uses < max_uses)
RETURNING id
```

If this returns 0 rows, the coupon is now at max uses (someone else grabbed the last use). Return an error to the user.

Use this pattern at the moment of payment, not at validation time. Validation is a preview — payment is the commitment.

## Summary

The coupon system has two phases:

**Phase 1 — Validate** (before checkout): Check all rules. Return the discounted price to show the user. Do NOT increment `current_uses` yet. Do NOT record a redemption yet.

**Phase 2 — Redeem** (at payment time): Atomically increment `current_uses`. Record the redemption. Apply the coupon to the Stripe payment. Fail gracefully if the coupon was already fully redeemed since validation.

This two-phase approach prevents double-counting while still giving users good UX (they see the discounted price before entering payment details).
