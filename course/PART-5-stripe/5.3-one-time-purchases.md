# Lesson 5.3 — One-Time Purchases

## The PaymentIntent Flow

One-time purchases use Stripe's **PaymentIntent** API. A PaymentIntent represents a single attempt to collect payment.

The flow:
1. Client requests to buy a product
2. Your server creates a PaymentIntent in Stripe
3. Your server returns the `client_secret` to the client
4. Client uses Stripe.js to confirm the payment (card details go directly to Stripe)
5. Stripe fires `payment_intent.succeeded` webhook
6. Your server processes the webhook and grants access

```javascript
// handlers/payments.js

export async function purchaseProduct(req, res) {
  const { product_id, payment_method_id, coupon_code } = req.body
  const user = req.user
  
  // 1. Validate the product
  const productResult = await db.query(`
    SELECT p.id, p.name, p.stripe_product_id,
           pr.id as price_id, pr.amount_cents, pr.currency, pr.stripe_price_id
    FROM products p
    JOIN prices pr ON pr.product_id = p.id AND pr.is_current = true
    WHERE p.id = $1 AND p.deleted_at IS NULL AND p.is_active = true
  `, [product_id])
  
  if (!productResult.rows.length) {
    return res.status(404).json({ error: { code: 'PRODUCT_NOT_FOUND', message: 'Product not found.' } })
  }
  
  const product = productResult.rows[0]
  
  // 2. Check user hasn't already purchased this product
  const alreadyOwned = await db.query(`
    SELECT id FROM user_product_access
    WHERE user_id = $1 AND product_id = $2
    LIMIT 1
  `, [user.id, product_id])
  
  if (alreadyOwned.rows.length) {
    return res.status(409).json({
      error: { code: 'ALREADY_PURCHASED', message: 'You already own this product.' }
    })
  }
  
  // 3. Validate and apply coupon
  let finalAmountCents = product.amount_cents
  let stripeCouponId = null
  
  if (coupon_code) {
    const coupon = await validateCoupon(coupon_code, user.id, 'product', product_id)
    if (!coupon.valid) {
      return res.status(400).json({ error: { code: coupon.reason, message: coupon.message } })
    }
    finalAmountCents = applyDiscount(product.amount_cents, coupon.discount_type, coupon.discount_value)
    stripeCouponId = coupon.stripe_coupon_id
  }
  
  // 4. Generate idempotency key (prevents duplicate charges on network retries)
  const idempotencyKey = `purchase_${user.id}_${product_id}_${Date.now()}`
  
  // 5. Create a payment record (pending)
  const paymentRecord = await db.query(`
    INSERT INTO payments (id, user_id, product_id, stripe_payment_intent_id, amount_cents, currency, status, idempotency_key)
    VALUES (uuid_generate_v4(), $1, $2, 'pending', $3, $4, 'pending', $5)
    RETURNING id
  `, [user.id, product_id, finalAmountCents, product.currency, idempotencyKey])
  // Note: stripe_payment_intent_id is 'pending' — we'll update it after creating the PaymentIntent
  
  // 6. Create Stripe PaymentIntent
  const stripeUser = await db.query(`SELECT stripe_customer_id FROM users WHERE id = $1`, [user.id])
  
  const paymentIntent = await stripe.paymentIntents.create({
    amount: finalAmountCents,
    currency: product.currency,
    customer: stripeUser.rows[0].stripe_customer_id,
    payment_method: payment_method_id,
    confirm: false,  // Client will confirm via Stripe.js
    metadata: {
      payment_record_id: paymentRecord.rows[0].id,
      user_id: user.id,
      product_id: product_id,
    },
  }, {
    idempotencyKey,  // Stripe-level idempotency
  })
  
  // 7. Update the payment record with the real PaymentIntent ID
  await db.query(`
    UPDATE payments
    SET stripe_payment_intent_id = $1
    WHERE id = $2
  `, [paymentIntent.id, paymentRecord.rows[0].id])
  
  // 8. Return client_secret for Stripe.js to confirm
  return res.status(201).json({
    payment_intent: {
      id: paymentIntent.id,
      client_secret: paymentIntent.client_secret,
      amount_cents: finalAmountCents,
      currency: product.currency,
    }
  })
}
```

## The Webhook Grants Access

After the client confirms payment via Stripe.js, Stripe fires `payment_intent.succeeded`. Your webhook handler (Lesson 5.5) updates the payment status and grants product access.

Never grant access before the webhook arrives. Never grant access because the client says payment succeeded.

## The Idempotency Key Pattern

```javascript
const idempotencyKey = `purchase_${user.id}_${product_id}_${Date.now()}`
```

This key is passed to Stripe. If the same request is made twice (network retry, double-click), Stripe returns the existing PaymentIntent instead of creating a new one.

Store the idempotency key in your `payments` table with a `UNIQUE` constraint. This prevents a duplicate payment record even if your code runs twice.
