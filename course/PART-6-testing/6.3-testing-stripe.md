# Lesson 6.3 — Testing the Stripe Flow

## Test Cards

Stripe provides test card numbers that simulate different scenarios. These only work in test mode.

| Card Number | Result |
|-------------|--------|
| 4242 4242 4242 4242 | Payment succeeds |
| 4000 0000 0000 0002 | Payment declined (generic decline) |
| 4000 0025 0000 3155 | Requires 3D Secure authentication |
| 4000 0000 0000 9995 | Insufficient funds |
| 4000 0000 0000 0069 | Card expired |

Use expiry: any future date. CVC: any 3 digits.

## Testing Webhooks with the Stripe CLI

The Stripe CLI forwards real webhook events to your local server. This is the correct way to test webhooks — not by simulating them in your tests.

```bash
# Terminal 1: Your server running
npm run dev

# Terminal 2: Stripe CLI forwarding
stripe listen --forward-to http://localhost:3000/api/v1/webhooks/stripe

# Terminal 3: Trigger test events
stripe trigger payment_intent.succeeded
stripe trigger customer.subscription.updated
stripe trigger customer.subscription.deleted
stripe trigger invoice.paid
stripe trigger customer.subscription.trial_will_end
```

For subscription events that need a real subscription ID:
```bash
# First create a subscription via your API (use test card)
# Then trigger events against it
stripe trigger customer.subscription.updated \
  --override customer.subscription:subscription=sub_xxx
```

## Testing Idempotency

The most important webhook property to test: firing the same event twice should process it once.

```javascript
// tests/integration/webhooks.test.js
import { stripe } from '../../src/services/stripe.js'
import * as webhookHandlers from '../../src/handlers/webhooks.js'
import { processWebhookEvent } from '../../src/routes/webhooks.js'

describe('Webhook Idempotency', () => {
  test('processing the same event twice results in one processing', async () => {
    // Construct a fake Stripe event (with a fixed ID)
    const fakeEvent = {
      id: 'evt_test_idempotency_001',
      type: 'invoice.paid',
      data: {
        object: {
          id: 'in_test_001',
          subscription: 'sub_test_active_001',  // from test seed
          amount_paid: 1999,
          status: 'paid',
        }
      }
    }
    
    // Process it once
    await processWebhookEvent(fakeEvent)
    
    // Check it was processed
    const firstProcessing = await db.query(`
      SELECT processed_at FROM webhook_events WHERE stripe_event_id = $1
    `, [fakeEvent.id])
    expect(firstProcessing.rows[0].processed_at).not.toBeNull()
    
    // Get the subscription status after first processing
    const subAfterFirst = await db.query(`
      SELECT status FROM subscriptions WHERE stripe_subscription_id = 'sub_test_active_001'
    `)
    
    // Process it again (simulating Stripe retry)
    await processWebhookEvent(fakeEvent)
    
    // Status should not have changed from a second processing
    const subAfterSecond = await db.query(`
      SELECT status FROM subscriptions WHERE stripe_subscription_id = 'sub_test_active_001'
    `)
    
    expect(subAfterFirst.rows[0].status).toBe(subAfterSecond.rows[0].status)
    
    // Only one webhook_event record
    const events = await db.query(`
      SELECT COUNT(*) FROM webhook_events WHERE stripe_event_id = $1
    `, [fakeEvent.id])
    expect(parseInt(events.rows[0].count)).toBe(1)
    
    // Cleanup
    await db.query(`DELETE FROM webhook_events WHERE stripe_event_id = $1`, [fakeEvent.id])
  })
})
```

## Testing Grandfathering

```javascript
describe('Grandfathering: Correct price is used', () => {
  test('user grandfathered at old price is not charged new price', async () => {
    // Setup: create a subscription at price_A (old price)
    const oldPrice = await db.query(`
      SELECT id, amount_cents FROM prices WHERE plan_id = (
        SELECT id FROM plans WHERE name = 'Monthly'
      ) ORDER BY created_at ASC LIMIT 1
    `)
    
    const memberToken = await loginAs('member@test.com')
    
    // Create subscription (locked to old price)
    // In a real test, this would go through the full API with test Stripe
    const sub = await db.query(`
      SELECT locked_price_id, plan_id FROM subscriptions
      WHERE user_id = (SELECT id FROM users WHERE email = 'member@test.com')
        AND status IN ('active', 'trialing')
      LIMIT 1
    `)
    
    // Admin creates a new (higher) price
    const adminToken = await loginAs('admin@test.com')
    const productOrPlanId = sub.rows[0].plan_id
    
    await request(app)
      .post(`/api/v1/plans/${productOrPlanId}/prices`)
      .set('Authorization', `Bearer ${adminToken}`)
      .send({ amount_cents: 2999, applies_to: 'future_members' })
    
    // Verify: member's subscription still has the OLD locked price
    const subAfter = await db.query(`
      SELECT locked_price_id FROM subscriptions
      WHERE user_id = (SELECT id FROM users WHERE email = 'member@test.com')
        AND status IN ('active', 'trialing')
      LIMIT 1
    `)
    
    // locked_price_id should NOT have changed to the new price
    expect(subAfter.rows[0].locked_price_id).toBe(sub.rows[0].locked_price_id)
    
    // The locked price should still be the old amount
    const lockedPrice = await db.query(`
      SELECT amount_cents FROM prices WHERE id = $1
    `, [sub.rows[0].locked_price_id])
    
    expect(lockedPrice.rows[0].amount_cents).toBeLessThan(2999)
  })
})
```

## Testing Signature Verification

```javascript
describe('Webhook Signature Verification', () => {
  test('rejects webhook with invalid signature', async () => {
    const payload = JSON.stringify({ id: 'evt_fake', type: 'test' })
    
    const res = await request(app)
      .post('/api/v1/webhooks/stripe')
      .set('Content-Type', 'application/json')
      .set('stripe-signature', 'invalid_signature_here')
      .send(payload)
    
    expect(res.status).toBe(400)
    expect(res.body.error).toBe('Invalid signature')
  })
  
  test('accepts webhook with valid signature', async () => {
    const payload = JSON.stringify({ id: 'evt_valid_test', type: 'payment_intent.succeeded', data: { object: {} } })
    
    // Generate a valid signature using the test webhook secret
    const timestamp = Math.floor(Date.now() / 1000)
    const signature = stripe.webhooks.generateTestHeaderString({
      payload,
      secret: config.stripe.webhookSecret,
    })
    
    const res = await request(app)
      .post('/api/v1/webhooks/stripe')
      .set('Content-Type', 'application/json')
      .set('stripe-signature', signature)
      .send(payload)
    
    expect(res.status).toBe(200)
    expect(res.body.received).toBe(true)
  })
})
```
