# Lesson 9.2 — Project Setup: Axum + Tokio + SQLx

## Prerequisites

```bash
# Install Rust (if not installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install SQLx CLI (for running migrations)
cargo install sqlx-cli --no-default-features --features postgres

# Verify
rustc --version   # Should be 1.75+
cargo --version
sqlx --version
```

## Create the Project

```bash
cargo new saas-backend
cd saas-backend
```

## SQLx Setup

SQLx verifies queries at compile time against your actual database. Run migrations first:

```bash
# Set DATABASE_URL in your environment
export DATABASE_URL=postgres://postgres:password@localhost:5432/saas_dev

# Run migrations
sqlx migrate run

# Prepare the query cache (for compile-time verification)
cargo sqlx prepare
```

The `cargo sqlx prepare` command connects to your database, analyzes all queries in your code, and saves the schema information to `.sqlx/` directory. Commit this directory — CI can then verify queries without a database connection.
