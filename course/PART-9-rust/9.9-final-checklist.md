## Build and Test

```bash
# Compile with zero warnings
cargo build --release 2>&1 | grep -E "(error|warning)"

# Run all tests (unit + integration)
cargo test

# Run only unit tests (fast — no DB needed)
cargo test --lib

# Run with output for debugging
cargo test -- --nocapture
```

## SQLx Compile-Time Query Verification

```bash
# Prepare the query cache (commit this to git)
cargo sqlx prepare

# Verify all queries compile against the schema
cargo sqlx prepare --check
```

The `--check` flag fails CI if queries don't match the current schema. Add this to your CI pipeline.

```rust
// tests/auth_test.rs
#[cfg(test)]
mod tests {
    use axum_test::TestServer;
    use serde_json::json;

    async fn create_test_server() -> TestServer {
        dotenvy::dotenv().ok();
        // Setup test app with test database
        // (see full test helper in tests/helpers.rs)
        todo!()
    }

    #[tokio::test]
    async fn test_register_and_login() {
        let server = create_test_server().await;

        let response = server
            .post("/api/v1/auth/register")
            .json(&json!({
                "email": "test@example.com",
                "password": "SecurePass123!",
                "display_name": "Test User"
            }))
            .await;

        response.assert_status_created();
        let body = response.json::<serde_json::Value>();
        assert!(body["access_token"].is_string());
        assert_eq!(body["user"]["email"], "test@example.com");
    }

    #[tokio::test]
    async fn test_policy_member_cannot_edit_other_profile() {
        // Test ABAC policy — unit test version (no HTTP needed)
        use saas_backend::auth::extractor::AuthUser;
        use saas_backend::policies::can_edit_profile;

        let user1_id = uuid::Uuid::new_v4();
        let user2_id = uuid::Uuid::new_v4();

        let user1 = AuthUser {
            id: user1_id,
            email: "user1@test.com".to_string(),
            role: "member".to_string(),
            organization_id: None,
        };

        // Member can edit own profile
        assert!(can_edit_profile(&user1, user1_id, false));

        // Member cannot edit other's profile
        assert!(!can_edit_profile(&user1, user2_id, false));
    }
}
```

## What's Left to Actually Deploy

1. **Infrastructure:** PostgreSQL + Redis on your cloud provider
2. **Stripe webhook:** Register your production URL in Stripe Dashboard
3. **Environment:** Set all `_REPLACE_ME` values in production `.env`
4. **Build:** `cargo build --release` produces `target/release/saas-backend`
5. **Run:** `./target/release/saas-backend`

For Docker:
```dockerfile
FROM rust:1.75 AS builder
WORKDIR /app
COPY . .
RUN cargo build --release

FROM debian:bookworm-slim
WORKDIR /app
COPY --from=builder /app/target/release/saas-backend .
CMD ["./saas-backend"]
```
